# 🐺 Black Wolf Booking App UI  

A sleek and modern **Booking App UI** built with **React (Vite)**, designed to deliver a smooth user experience with **Dark Mode**, **Responsive Layouts**, and **Clerk Authentication**.  

🔗 **Live Demo**: [Black Wolf Booking App UI](https://black-wolf-booking-app-ui.vercel.app/)  

---

## 🚀 Features  

- 🌙 **Dark Mode support** for modern look & feel  
- 📱 **Responsive design** – optimized for desktop, tablet, and mobile  
- 🔐 **Clerk Authentication** – secure login & sign-up flow  
- 🖥️ **Dashboard UI** that unlocks when the user signs in  
- 🎨 **Modern UI/UX** design principles applied  

---

## 🛠️ Tech Stack  

- **Frontend**: React + Vite  
- **Styling**: TailwindCSS  
- **Auth**: Clerk  
- **State Management & UI**: React Hooks

## ⚙️ Installation & Setup


### Clone repo
git clone https://github.com/your-username/black-wolf-booking-app-ui.git

### Navigate into project
cd black-wolf-booking-app-ui

### Install dependencies
npm install

### Add environment variables for Clerk
### .env file
VITE_CLERK_FRONTEND_API=your_clerk_api_here

### Start dev server
npm run dev

----------------
## 📦 Build for Production
npm run build
